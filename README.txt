Mirrodex — 처음 쓰는 분도 따라가는 화면 연결 도우미
====================================================
(English: README_EN.txt)

처음 시작하기
  1. 압축을 풀기 전에 차단을 해제하십시오.
     받은 ZIP 파일을 마우스 오른쪽 버튼으로 눌러 '속성'을 여십시오.
     아래쪽 '보안: 이 파일은 다른 컴퓨터에서 가져왔으므로…' 옆의 '차단 해제'에 체크하고 '확인'을 누르십시오.
     ('차단 해제'가 보이지 않으면 이미 해제된 것입니다.)
  2. ZIP 파일을 마우스 오른쪽 버튼으로 눌러 '압축 풀기'를 선택하십시오.
     압축된 파일 안에서 바로 실행하지 말고, 풀린 폴더를 여십시오.
  3. 휴대폰 잠금을 풀고 컴퓨터에 케이블로 연결하십시오.
  4. 'Install Mirrodex.bat'을 두 번 누르면 이 PC에 설치되고 시작 메뉴·바탕화면에 바로가기가 생깁니다.
     (설치하지 않고 쓰려면 Mirrodex.bat을 두 번 누르십시오.)
  5. 휴대폰 화면이 바로 나타납니다. 연결 방식(케이블/무선)에 맞는 기본값으로 시작합니다.
     처음에는 영어로 나옵니다. 창 오른쪽 위의 '한국어' 버튼을 누르면 한국어로 바뀌고 다음에도 유지됩니다.
     화면이 불편하면 옆 메뉴의 '도우미로 화면 맞추기'를 누르십시오.

  'Windows의 PC 보호' 파란 창이 나타나면
    Mirrodex에는 아직 코드 서명이 없어 Windows가 처음 보는 프로그램으로 경고합니다.
    '추가 정보'를 누른 뒤 '실행'을 누르십시오.
    이미 압축을 풀었다면 1번처럼 ZIP의 차단을 해제한 뒤 폴더를 지우고 다시 푸는 것이 가장 간단합니다.

도우미가 해 주는 일
  · 화면 연결 엔진이 폴더에 함께 들어 있어 따로 설치할 것이 없습니다.
  · 휴대폰이 연결되지 않으면 케이블과 휴대폰 설정을 안내합니다.
  · 휴대폰에서 연결 허용이 필요하면 무엇을 눌러야 하는지 알려 줍니다.
  · 화면을 30초 보여 준 뒤 '잘 보입니다 / 끊깁니다 / 흐릿합니다 / 반응이 늦습니다'를 묻습니다.
  · 불편한 점에 맞춰 한 가지 설정만 바꿔 비교합니다. 숫자나 기술 용어를 알 필요가 없습니다.
  · 더 좋아졌다고 선택한 설정만 저장합니다. 비슷하거나 모르겠으면 현재 값을 유지합니다.

시험 중 화면이 닫혀도 고장이 아닙니다
  시험 화면은 30초 뒤 자동으로 닫히고 안내창으로 돌아옵니다.
  설정 비교는 현재 → 바꿔 본 화면 → 현재 순서로 약 90초 진행합니다.
  같은 앱에서 같은 동작을 해 보십시오. 글씨, 움직임, 반응을 함께 비교하십시오.
  휴대폰 자체 화면은 꺼질 수 있습니다. 컴퓨터에 보이는 화면을 마우스로 조작하십시오.
  화면이 잠겨 있다면 휴대폰의 전원 버튼으로 켜고 잠금을 풀어 주십시오.

다음부터 쓰기
  바탕화면의 Mirrodex를 누르면 저장된 설정으로 바로 시작합니다.
  마우스로 누르거나 끌어서 조작하십시오. 끝낼 때는 미러링 창의 X를 누르십시오.

다시 도움받기
  미러링 창 옆 메뉴의 '도우미로 화면 맞추기'를 누르십시오. 미러링을 끄지 않아도 됩니다.
  화면이 아예 열리지 않으면 안내 창에서 '도우미로 화면 다시 맞추기'를 고르십시오.
  (예전 버전의 'Mirrodex 도우미' 바로가기는 이제 필요 없어 자동으로 지워집니다.)
  이미 잘 보인다면 설정을 더 바꿀 필요는 없습니다.
  도우미를 닫으면 아직 확인하지 않은 시험 설정은 저장하지 않습니다.
  앞에서 '더 좋습니다'로 확인해 저장한 설정은 남습니다.

계속 불편하다면
  · 케이블을 컴퓨터에 직접 꽂아 보고, 충전만 되는 케이블이면 다른 케이블을 써 보십시오.
  · 무선이라면 공유기 가까이 이동해 보십시오. 처음에는 케이블 연결이 쉽습니다.
  · 휴대폰 자체에서도 끊기는지 확인해 주십시오. 휴대폰이 뜨거우면 잠시 쉬었다 다시 해 보십시오.
  · 글씨가 작으면 컴퓨터의 미러링 창을 크게 해 보십시오.
  도우미는 한 번에 최대 다섯 가지 변경을 비교합니다. 모든 환경에서 완벽한 성능을 보장하지 않습니다.

휴대폰 연결 허용
  도우미가 안내하면 휴대폰의 USB 디버깅을 켜야 합니다.
  설정 > 휴대전화 정보 > 소프트웨어 정보 > 빌드번호를 7번 누른 뒤,
  설정 > 개발자 옵션 > USB 디버깅을 켜십시오.
  신뢰하는 본인 컴퓨터에만 연결을 허용하십시오.
  삼성 자동 차단 때문에 설정이 잠겼다면 관련 USB 명령 차단 설정을 확인하십시오.

익숙한 사용자를 위한 기능
  Mirrodex.bat guide     버튼형 도우미
  Mirrodex.bat setup     환경별 시작 설정 선택 (현재 설정 유지 가능)
  Mirrodex.bat tune      항목별 직접 비교
  Mirrodex.bat diagnose  기기 정보 확인
  새 환경의 시작점: USB 1024/60fps/8M/50ms, 무선 1024/60fps/6M/100ms,
  저부하 800/30fps/4M/50ms. 실제 HW 인코더 목록과 기기 해상도를 반영합니다.
  기존 사용자 설정은 보존합니다. 모델명만 보고 주사율을 강제하지 않습니다.
  무선 연결/페어링은 자동 수행하지 않습니다.

단축키
  Alt+F 전체화면 / Alt+H 홈 / Alt+B 또는 Alt+Backspace 뒤로가기
  Alt+O 폰 화면 끄기 / Alt+Shift+O 켜기 / Alt+I FPS 표시

설정과 복원
  mirrodex.cfg: 저장된 설정. 직접 편집하지 않아도 됩니다.
  mirrodex.cfg.bak: 설정을 바꾸기 전의 파일.
  refresh-recovery.cfg: 주사율 강제 기능의 복원 기록. 임의로 지우지 마십시오.
  이 기록이 남으면 해당 폰을 다시 연결하고 Mirrodex를 실행해 복원을 완료하십시오.
  기존 arr 옵션은 호환용으로만 읽으며 휴대폰 주사율을 변경하지 않습니다. 미러링 FPS 상한은 별도로 유지합니다.

기존 기능은 유지합니다
  마우스·키보드, 클립보드, 노트북으로 소리 전달, 폰 화면 끄기, 충전 중 절전 방지,
  PC 화면보호기 방지, 바로가기.

추가된 복구·환경 안내 (2026-09-28)
  · 기존 사용자도 연결이 없거나 허용이 필요하면 버튼형 안내가 나타납니다.
  · 도우미 첫 화면에서 '저장하지 않고 사용', '정상 설정 복원', '직전 변경 취소'를 고를 수 있습니다.
  · 처음 '잘 보입니다'로 확인한 설정을 정상 복원점으로 따로 보관합니다.
    이후 일반 저장은 이 복원점을 덮어쓰지 않습니다. 도우미 '다른 선택'의 '다른 방법으로 마치기'에서
    '현재 화면을 정상 설정으로 지정'을 눌렀을 때만 교체합니다.
  · 비교는 30초 또는 10초를 고를 수 있습니다. 건너뛰기/중단은 새 설정을 채택하지 않습니다.
    비교는 1 · 2 · 1 원판으로 표시합니다(1 = 현재, 2 = 바꿔 본 화면). 시험 창은 미러링 창 옆에 붙어
    남은 시간을 줄어드는 선으로 보여 주며, 창 위치·크기를 이어서 사용합니다.
  · 다섯 번 비교 후에는 임시 사용·복원·문제 정보 저장으로 마칠 수 있습니다.
  · 연결 끊김은 같은 폰을 재연결하도록 안내합니다. 인코더 실패가 명확할 때만
    기기 목록에 있는 다른 인코더를 한 번 제안하며, 사용자 확인 없이 저장하지 않습니다.
  · 휴대폰/PC/USB·무선/선택 화면의 이름·해상도로 환경을 구분합니다.
    실행할 때 마우스가 있는 모니터를 기준으로 합니다. 모니터 주사율·GPU 드라이버·
    케이블 품질·무선 혼잡의 변화는 감지하지 못하므로 이 경우 도우미를 다시 사용하십시오.
  · profiles 폴더의 good.cfg는 정상 복원점, previous.cfg는 직전 설정입니다.
    일반 사용자는 이 파일을 직접 편집할 필요가 없습니다.
  · 문제 정보 저장은 diagnostics 폴더에 설정·오류 종류·최근 실행의 FPS 요약을 저장합니다.
    FPS 수집은 짧은 시험에서만 켭니다. 정지 화면의 낮은 FPS는 정상일 수 있으며
    건너뛴 프레임 수는 네트워크 손실률이 아닙니다. 숫자로 설정을 자동 채택하지 않습니다.
    화면·클립보드·기기 일련번호·원본 로그는 진단 파일에 넣지 않고 외부로 전송하지 않습니다.
  · 이번 업데이트는 이미 실행 중인 화면을 종료하지 않습니다. 다음 실행부터 적용됩니다.

사이드 메뉴와 Discord 방송
  미러링이 시작되면 영상 창 옆에 메뉴가 표시됩니다. 위에서부터 이렇게 놓여 있습니다.
  · 지금 카드: 보여줄 화면(옆의 '바꾸기'로 변경), 해상도·fps·전송량·압축, 기기·연결 방식,
    상태 칩(녹화 중 시간, 재연결 잠금, '저장된 설정' 또는 '이번 실행에만 쓰는 설정'), 작업 결과.
    스크린샷·녹화·문제 정보를 저장하면 '파일 위치 열기'로 바로 폴더를 열 수 있습니다.
  · 키 네 개: 화면 녹화, 스크린샷 저장(사진\Mirrodex, 미러링을 끊지 않음), 항상 위에 표시, 방송 중 재연결 잠금.
    켜고 끄는 키는 오른쪽 위 작은 원이 켜짐(채움)/꺼짐(빈 원)을 보여 줍니다.
  · 화면: '도우미로 화면 맞추기'는 미러링 중에도 비교 도우미를 열고, 끝나면 미러링을 이어 갑니다.
    화면 설정은 접혀 있습니다. '화면 설정 펼치기'를 누르면
    해상도·프레임 상한·전송량·영상/소리 완충·코덱·소리 출력을 선택할 수 있습니다.
  · 연결: 무선으로 전환, 다른 휴대폰 추가 연결. 아래에 Discord 길라잡이·문제 정보 저장·업데이트 확인.
  ↻ 표시가 있는 동작은 화면이 잠시 다시 연결됩니다.
  값을 선택하는 동안에는 화면이 유지됩니다. 고르고 아직 적용하지 않은 값은 점선으로 표시되고 개수가 나옵니다.
  '변경 적용'을 누르면 잠시 재연결합니다. 바꾼 값이 없으면 같은 자리에서 '같은 설정으로 다시 연결'이 됩니다.
  적용은 이번 실행에만 반영합니다. 마음에 들면 '지금 실행 중인 설정 저장'을 누르십시오.
  정상 설정 복원은 사용자가 확인한 복원점으로 돌아갑니다.
  방송 중에는 '방송 중 · 재연결 잠금'을 켜서 실수로 연결을 끊지 않도록 하십시오.
  잠금 중에는 재연결하는 동작에 자물쇠가 표시되고 누를 수 없습니다.
  메뉴의 X는 메뉴만 최소화합니다. 작업 표시줄에서 다시 열 수 있습니다.
  Discord에서는 설정 창이 아닌 Mirrodex 영상 창을 선택하고 소리 공유를 켜십시오.
  재연결 후에는 Discord에서 공유 창을 다시 선택해야 할 수 있습니다.
  방송에 관한 자세한 판단과 점검 순서는 BROADCAST.md에 있습니다.

새 기능 (2026-09-29)
  · 무선 연결: 휴대폰이 연결되지 않았다는 안내에서 '무선으로 연결하기'를 누르면
    무선 디버깅의 페어링 코드로 케이블 없이 연결합니다(Android 11 이상).
    케이블로 연결된 상태라면 메뉴의 '무선으로 전환'을 누른 뒤 케이블을 뽑으면 됩니다.
  · 보여줄 화면: 메뉴 맨 위 '지금' 카드의 '바꾸기'에서 휴대폰 화면 전체 / 앱 하나만 / 후면·전면 카메라를 고릅니다.
    '앱 하나만'은 고른 앱을 별도 화면에 열어 알림과 다른 앱이 방송에 나오지 않습니다(Android 10 이상).
    카메라는 휴대폰 마이크 소리를 씁니다(Android 12 이상). Discord에서는 이 창을 공유하면 됩니다.
  · 항상 위에 표시: 미러링 창을 다른 창 위에 고정합니다. 선택은 다음 실행에도 유지됩니다.
  · 다른 휴대폰 추가 연결: 휴대폰마다 따로 미러링 창과 메뉴가 열립니다. 같은 휴대폰을 두 번 열지는 않습니다.
  · 다크 모드: Windows 설정의 앱 모드(라이트/다크)를 따릅니다.
