# 실제 환경 인수 검사

자동 검사는 실제 초보 사용자의 이해도나 물리적인 USB/무선 품질을 증명하지 않습니다.
현재 실행 중인 정상 미러링은 중단하지 않았습니다. 아래 검사는 미실시 항목입니다.

1. scrcpy·adb가 설치되지 않은 별도 Windows 계정/PC에서 배포 ZIP을 풉니다. 인터넷을 끈 상태에서도 Mirrodex가 설치 안내 없이 바로 연결 안내로 이어지는지 확인합니다. engine 폴더를 지우면 'ZIP을 다시 풀어 달라'는 안내가 보이고 설정이 저장되지 않아야 합니다.
2. 디버깅을 처음 허용하는 휴대폰으로 연결합니다. PC에 허용 안내가 보이고 폰에서 허용 후 '다시 연결 확인'으로 진행해야 합니다. 거절/닫기로 안전하게 나올 수 있어야 합니다.
3. 짧은 시험에서 동일 앱을 스크롤합니다. 현재→변경→현재 표시, 약 30초/10초 표시, 창 위치·크기를 확인합니다. '건너뛰기' 또는 시험 창 X로 닫았을 때 변경 후보가 저장되지 않아야 합니다.
4. 정상 화면 확인 후 인위적으로 버퍼 한 단계만 변경합니다. 도우미의 '정상 설정 복원'은 원래 정상 값, '직전 변경 취소'는 직전 값을 복원해야 합니다.
5. 별도의 시험 세션에서 USB를 뺍니다. 연결 끊김 안내가 나와야 합니다. 같은 폰을 다시 연결하고 재시도한 뒤 종료하면 기존 주사율이 복원되어야 합니다. 다른 폰만 연결했을 때는 그 폰을 변경하지 않아야 합니다.
6. 다른 PC/폰/이미 연결한 무선 ADB/다른 모니터에서 시작합니다. 환경 변경 안내가 나타나고 선택 없이 설정을 바꾸지 않아야 합니다. USB 정상 복원점이 무선 환경 복원점으로 제시되지 않아야 합니다.
7. '문제 정보 저장' 파일을 열어 일련번호, 화면, 클립보드, 원본 오류 로그가 없는지 확인합니다. 정지 화면의 낮은 FPS가 자동으로 나쁜 설정 판정을 만들지 않아야 합니다.
8. 컴퓨터 경험이 적은 사람에게 설명 없이 '폰 화면을 PC로 보고, 불편하면 원래대로 돌아가세요'만 요청합니다. 어느 안내에서 멈추는지, 잘못 누르는 버튼, 복원 성공 여부를 기록합니다. 이해하지 못한 문구가 있으면 실제 관찰에 맞춰 수정합니다.
9. 포켓몬 챔피언스가 설치된 휴대폰으로 확인합니다(2026-10-01 추가). ① USB 디버깅을 켠 상태에서 게임이 실행되는지. ② '포켓몬 챔피언스 실행'을 적용하면 게임이 열리고, 다음 실행은 잠금이 켜진 채 시작하는지. ③ 휴대폰 화면을 끈 상태와 켜 둔 상태에서 각각 조작과 스크린샷(Alt+])이 되는지. ④ '시작할 때 녹화'로 시작해 대전 중 Alt+[를 누르고, 창을 닫은 뒤 mp4가 재생되며 marks.txt의 시간이 경기 위치와 맞는지. ⑤ PC에 연결한 컨트롤러로 게임을 조작할 수 있는지, 안 되면 변경 전 설정으로 돌아오는지. ⑥ '앱 하나만'으로 게임을 띄운 뒤 설정을 적용(재연결)해도 게임이 종료되지 않는지. 랭크전이 아닌 화면에서 먼저 확인합니다.
   2026-10-01 SM-S948N으로 ①②③④⑥을 타이틀 화면에서 확인했습니다(결과는 REVIEW.md). 남은 것: ⑤ 실제 컨트롤러, ④의 mp4를 재생기로 여는 것, 실제 대전 중의 사용, 그리고 단축키를 누를 때 대전 화면에 영향이 없는지.

성능 평가는 같은 앱/화면/창 크기/전원 조건에서 비교합니다. 10~30초 확인 후에도 20분 이상 실제 사용하며 발열·끊김·글씨·입력 반응을 확인하세요. 다른 PC에서도 '완벽한 최적값'이라고 일반화하지 않습니다.
